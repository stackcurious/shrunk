## Regression sweep (nothing found)

- **Curated Browse cards stay unattributed.** `trending.json` products carry a
  `currentPrice` with no snapshots, so `storedPriceNow != nil`, `adoptedPrice`
  stays nil, and `priceIsFromStoreSnapshot` stays false. A curated card with
  *no* price at all does adopt the live one — and that price genuinely is
  Kroger's, so the attribution is correct rather than a leak.
- **Verdicts cannot move.** In the re-analyze branch `liveSize` is ignored
  whenever `product.sizeHistory` is non-empty (`ShrinkDetector.swift:32-35`),
  so re-running the detector after the live fetch cannot change a verdict
  derived from stored observations; only `priceNow` / `costPerUnitNow` /
  `priceIsFromStoreSnapshot` can newly populate.
- **`analyze` stays pure**, so `state = .loaded(product, adopted)` is a
  recompute, not a patch — the review's original reason for preferring this
  shape still holds.
- **CTA branches are mutually exclusive.** `outcome == .needsLabel` is
  intercepted first and implies `currentSize == nil`, which implies
  `.insufficientData`; the new `.unchanged`/`.grew` branch needs ≥2
  observations, so it can never collide with it.
- **No alert regressions.** `recordScannedShrink`'s `guard record.verdict.isShrink`
  and the `prebake == nil` gate are both untouched by this round.
